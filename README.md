# 🚀 Featured Projects

### 🚑 Emergency Mode Traffic Signal Simulation

**Python · PyTorch · YOLO · OpenCV · Streamlit**

An intelligent traffic-management system that detects ambulances using deep learning and dynamically prioritizes emergency traffic.

The system uses YOLO-based object detection to identify ambulances and triggers an automatic traffic-signal override, while a Streamlit interface visualizes the detection and signal state.

**Highlights**

* YOLO-based ambulance detection
* Real-time traffic-signal decision logic
* Emergency signal override
* OpenCV image processing
* Streamlit interface
* PyTorch-based deep learning

🔗 **[View Repository](https://github.com/Tharun0707/Machine-Learning-Based-Emergency-Mode-Traffic-Signal-Simulation)**
